الاتصال غير مكتمل

أكمل إعداد Supabase للوصول إلى السجل.

  1. 1

    ضع Project URL وanon public key في ملف config.js.

  2. 2

    نفّذ ملف supabase-schema.sql كاملًا في SQL Editor.

  3. 3

    أعد تحميل الصفحة، ثم أنشئ حسابك وسجّل الدخول.

التفاصيل موجودة في ملف README.md. لا تستخدم مفتاح service_role في المتصفح.

حماية البيانات

سجلك لك وحدك.

كل مستخدم يمتلك مساحة معزولة. حتى لو شاركتم رابط التطبيق نفسه، فإن قاعدة البيانات تمنع أي حساب من رؤية سجلات حساب آخر.

  • عزل على مستوى الصفوفسياسات RLS تربط كل سجل بمالكه عبر auth.uid().
  • جلسة موثّقةتسجيل الدخول عبر Supabase Auth مع تجديد آمن للجلسة.
  • بيانات في السحابةلا سجلات مرضى في LocalStorage؛ المصدر الوحيد هو Supabase.

استخدم بيانات مرضى مجهولة الهوية، والتزم بسياسات مؤسستك لحماية الخصوصية.
